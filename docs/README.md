## 💡 What is MiBlend ?

**MiBlend** is a modern alternative to Mcprep, built from scratch without forking the original project.  
It offers new, modern tools and a more flexible workflow for creating **Minecraft** content in **Blender**.

## 🎯 Why use MiBlend ?

MiBlend was created to:
- fix shortcomings of Mcprep
- provide convenient tools for fast and high-quality scene creation
