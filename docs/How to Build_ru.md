# Windows:
1. Скачайте любой бранч
2. Проверьте чтобы у вас был установлен python на компе, если нет, то установите [от сюда](https://www.python.org/downloads/)
3. Запустите build_windows.bat
4. Усё

# Linux
1. Скачайте любой бранч
2. Проверьте, чтобы у вас был установлен python на компе, если нет, то установите через пакетник вашего дистрибутива (Обычно пайтон не установлен на арче, так что вот команда для него sudo pacman -S python)
3. Установите bab через команду pip install bpy-addon-build
4. Пропишите команду bab в папке MiBlend (Не в папке MiBlend_Source !)
5. Усё
