# Assets

## Reload Assets List
Описание: Функция для перезагрузки списка ассетов

### Что делает эта фича ?
1. Удаляет все ассеты из списка
2. Добавляет все ассеты из папки Assets в список

## Add Asset
Описание: Функция для добавления ассета в список

### Что делает эта фича ?
1. Добавляет указанный ассет в список

P.S Если указать файл .json как ассет, то он будет добавлен лишь для этой сцены, а если указать архив .zip, то он будет добавлен в папку ассетов аддона

## Import Asset (Run Script) (Import Rig) (Import Material) (Import Model) (Import Shader Node) (Import Compositor Node)
Описание: Функция для импорта ассета

### Что делает эта фича ?
В зависимости от типа ассета (скрипт, риг, материал, модель, шейдер или композитор), функция импортирует его в текущий проект Blender. 
Для скриптов - исполняет их, для ригов и моделей - создает их в сцене, для нод - добавляет их в соответствующие редакторы нод.
