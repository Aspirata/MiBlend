# Разделы

<Tabs>
  <TabItem label="World" value="world">

  **Панель «World»** — исправление и оптимизация импортированных из майнкрафта миров.

  ## Fix World
  **Функционал:** автоматическая настройка материалов и текстур для корректного отображения в Minecraft.

  **Что делает:**
  1. Устанавливает режим прозрачности Dithered (Hashed) для корректного отображения полупрозрачных текстур.
  2. Настраивает фильтрацию текстур без размытия, сохраняя чёткий пиксель-арт.
  3. Интегрирует альфа‑канал текстуры с прозрачностью материала (Principled BSDF).
  4. Подключает карту эмиссии для светящихся блоков к параметру Emission.

  **Настройки:**
  - **Animated UV Fix** — добавляет ноду в шейдерах, которая исправляет вид анимированных текстур без их непосредственной анимации.
  - **Lazy Biome Color Fix** — добавляет базовую цветокоррекцию травы в соответствии с цветом биома.
  - **Backface Culling** — включает отсечение невидимых граней для стекла, листвы и других прозрачных элементов.

  </TabItem>

  <TabItem label="Resource Packs" value="resource-packs">

  **Панель «Resource Packs»** — работа с ресурс-паками.

  ## Reload Packs List
  **Функционал:** обновление встроенных ресурс-паков MiBlend.

  **Что делает:**
  1. Очищает список от встроенных по умолчанию паков.
  2. Проверяет наличие новых версий встроенных паков (Отключается в настройках аддона).
  3. Добавляет в список все пакеты из папки Resource Packs.

  ## Add Resource Pack (+)
  **Функционал:** добавление пользовательских ресурс-паков.

  **Что делает:**
  - Включает выбранную папку или архив в общий список.

  **Параметры:**
  - **Mode (Temporarily / Permanently)**
    - **Temporarily (по умолчанию)** — действует только для текущего проекта;
    - **Permanently** — сохраняет пакет для всех проектов.
  - **Type**
    - **Automatic (по умолчанию)** — автодетект типа пакета;
    - **Texture & PBR** — содержит классические и PBR‑текстуры;
    - **Texture** — только классические текстуры;
    - **PBR** — только PBR‑текстуры.

  ## Apply Resource Packs
  **Функционал:** массовое применение ресурс-паков к материалам.

  **Настройки:**
  - **Combine Duplicates** — объединяет дублирующиеся текстуры.
  - **Use Image Texture** — заменяет стандартные текстуры на изображения из пакета.
  - **Use PBR Textures** — применяет PBR‑карты.
  - **Animate Textures**
    - **Interpolate** — сглаживает анимацию;
    - **Randomize Speed** — назначает случайную скорость каждому фрейму.

  </TabItem>

  <TabItem label="Environment" value="environment">

  **Панель «Environment»** — создание окружения в стиле Minecraft.

  ## Create Environment
  **Функционал:** генерирует небо, облака и туман при помощи шейдеров.

  **Настройки:**
  - **Create Clouds** — создаёт облака;
  - **Create Sky** — добавляет небо;
  - **Create Fog** — включает туман.

  ## Recreate Environment
  **Функционал:** восстанавливает элементы окружения, если они повреждены или заменены.

  **Режимы работы:**
  - **Reset Settings** — сбрасывает все параметры окружения;
  - **Create Sky / Add Sky** — восстанавливает небо из исходного файла;
  - **Create Clouds / Add Clouds** — возвращает облака;
  - **Create Fog / Add Fog** — возвращает туман;
  - **Recreate Sky / Clouds / Fog** — полностью удаляет и заново добавляет соответствующий элемент.

  </TabItem>

  <TabItem label="Materials" value="materials">

  **Панель «Materials»** — упрощённые и ускоренные инструменты для работы с материалами.

  ## Fix Materials
  **Функционал:** базовая настройка материалов для корректного отображения.

  **Что делает:**
  1. Устанавливает Dithered прозрачность;
  2. Настраивает чёткую фильтрацию текстур;
  3. Связывает альфа‑канал текстуры с прозрачностью (Principled BSDF).

  ## Swap Textures
  **Функционал:** замена текстур в материалах.

  **Что делает:**
  - Ищет файлы текстур с тем же именем в указанной папке и подставляет их вместо исходных.

  </TabItem>

  <TabItem label="Procedural PBR" value="ppbr">

  **Панель «Procedural PBR»** — процедурные эффекты PBR для материалов.

  ## Set Procedural PBR
  **Функционал:** улучшает внешний вид материалов с помощью процедурных эффектов.

  **Настройки:**
  1. **Normals** — генерирует нормали или ноду bump;
      * **Bump/Normals** - Bump использует ноду bump, Normals - создаёт процедурные нормали из albedo текстуры похожим методом на шейдер Compementary в майнкрафте

  2. **Emission** — создаёт свечение;
      * **Camera Emission Strength** - Определяет силу излучения для камеры
      * **Non-Camera Emission Strength** - Определяет силу излучения для физики
      * **Randomize Emission Strength** - Включает рандомизацию силы излучения для каждого фейса
      * **Custom Config** - Использует заранее заданные настройки излучения для разных блоков

  3. **Principled BSDF Tweaks** — Изменяет настройки ноды Principled BSDF в шейдерах;
      * **Specular** - Изменяет Specular всем материалам
      * **Roughness** - Изменяет Roughness всем материалам
      * **Subsurface Scattering** — Добавляет эффект подповерхностного рассеивания (SSS) для травы и листвы;
      * **Metal** — Повышает металличность «металлических» материалов;
      * **Reflections** — Снижает Roughness для отражающих поверхностей, усиливая отражения.
      * **Translucency** — Добавляет полупрозрачность для листвы;
  </TabItem>

  <TabItem label="Procedural PBR" value="assets">

  **Панель «Assets»** — различные ассеты встроенные в MiBlend.

  ## Reload Assets List  
  **Описание:** Перезагружает список ассетов.

  ### Что делает:
  1. Удаляет все текущие ассеты из списка.  
  2. Добавляет все временные и постоянные ассеты обратно в список.

  ---

  ## Add Asset (+)
  **Описание:** Добавляет новый ассет в список.

  ### Что делает:
  1. Включает указанный ассет в общий список.  

  > **P.S.**  
  > - Если вы укажете файл `.json`, он будет добавлен только для текущей сцены (временно).  
  > - Если вы выберете архив `.zip`, он будет сохранён в папке ассетов аддона (навсегда).

  ---

  ## Import Asset  
  *(Run Script / Import Rig / Import Material / Import Model / Import Shader Node / Import Compositor Node)*  
  **Описание:** Импортирует выбранный ассет в текущий проект Blender.

  ### Что делает:
  - **Скрипты:** выполняются автоматически.  
  - **Риги и модели:** аппендятся в сцену.  
  - **Шейдерные и композиторные ноды:** добавляются в соответствующие редакторы нод.  
  - **Материалы:** подгружаются и связываются с объектами.

  ---

  ## История системы ассетов

  1. **MiBlend v0.3.x – 0.4.x**  
    **No Name**  
    Простая система без официального названия. Позволяла быстро и удобно добавлять риги в сцену.

  2. **MiBlend v0.5.x**  
    **UAS v1 (Universal Assets System)**  
    Первая полноценная версия: добавлены скрипты и категорийный выбор ассетов. Интерфейс GUI был полностью переработан.

  3. **MiBlend v0.6.x (текущая версия)**  
    **UAS v2.x.x (Universal Assets System)**  
    Полностью переписанная система: вместо категорий используются теги.  
    Поддержка ригов, скриптов, моделей, материалов, шейдерных, геометрических и композиторных нод.  
    Каждый ассет может включать собственный скрипт для расширенной логики импорта.  
    Новый GUI с улучшенными настройками прямо в аддоне.
