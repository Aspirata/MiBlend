# Assets

## Reload Assets List
Описание: Функция для перезагрузки списка ассетов

### Что делает эта фича ?
1. Удаляет все ассеты из списка
2. Добавляет все ассеты из папки Assets в список

## Add Asset
Описание: Функция для добавления ассета в список

### Что делает эта фича ?
1. Добавляет указанный ассет в список

P.S Если указать файл .json как ассет, то он будет добавлен лишь для этой сцены, а если указать архив .zip, то он будет добавлен в папку ассетов аддона

## Import Asset (Run Script) (Import Rig) (Import Material) (Import Model) (Import Shader Node) (Import Compositor Node)
Описание: Функция для импорта ассета

### Что делает эта фича ?
В зависимости от типа ассета (скрипт, риг, материал, модель, шейдер или композитор), функция импортирует его в текущий проект Blender. 
Для скриптов - исполняет их, для ригов и моделей - создает их в сцене, для нод - добавляет их в соответствующие редакторы нод.

## История системы ассетов
1. **MiBlend v0.3.x - 0.4.x**

**No Name** - простая система без названия, которая позволяла добавлять риги в сцену максимально простым, но в то же время рабочим способом.

2. **MiBlend v0.5.x**

**UAS v1 (Universal Assets System)** - первая версия системы ассетов, которая позволяла добавлять в сцену не только риги, но и скрипты, а также имела категории ассетов. GUI был переделан с нуля

3. **MiBlend v0.6.x - Самая последняя версия**

**UAS v2.x.x (Universal Assets System)** - вторая, и самая последняя, версия системы ассетов, которая была полностью переписана как снаружи, так и внутри. Вместо категорий используются теги.
Теперь поддерживаются не только риги и скрипты, но и модели, материалы, шейдерные, геометрические и композиторные ноды. 
Ассеты теперь имеют настройки прямо из GUI аддона, а его вид был улучшен по сравнению с прошлой версией.
