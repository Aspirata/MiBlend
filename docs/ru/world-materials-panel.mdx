# Разделы:

    <TabItem label="World" value="world">
        Описание: Раздел для исправления мира

        ## Fix World
        Описание: Функция для оптимизации и исправления материалов мира Minecraft

        ### Что делает эта фича ?

        1. Устанавливает режим прозрачности на Dithered (Hashed) для корректного отображения прозрачных текстур
        2. Настраивает правильную интерполяцию текстур для сохранения пиксельной графики
        3. Корректно соединяет альфа-канал текстуры с прозрачностью материала (Principled BSDF)
        4. Автоматически настраивает эмиссию для светящихся блоков, подключая текстуру к параметру Emission

        ### Настройки:

        * **Backface Culling** - Включает Backface Culling для некоторых прозрачных блоков (стекло, листва и т.д.)

        * **Delete Useless Textures** - Очищает материалы от неиспользуемых текстурных нод

        * **Lazy Biome Color Fix** - Добавляет простую цветокоррекцию для травы в соответствии с цветом биома
    </TabItem>

    <TabItem label="Resource Packs" value="resource packs">
        Описание: Раздел для работы с ресурс паками

        ## Reload Default Packs
        Описание: Функция для перезагрузки встроенных в MiBlend ресурс паков

        ### Что делает эта фича ?
        1. Удаляет все встроенные в MiBlend ресурс паки из списка
        2. Проверяет наличие обновления для встроенных ресурс паков
        3. Добавляет в список ресурс паки из папки Resource Packs

        ## Add Resource Pack
        Описание: Функция для добавления ресурс пака в список

        ### Что делает эта фича ?
        Добавляет указанную папку или архив в список ресурс паков

        ### Настройки:
        * **Mode (Temporarily/Permanently)** - Изменяет метод добавления ресурс пака в список
        
            **Temporarily (по умолчанию)** - Добавляет ресурс пак в список только для этого файла
            
            **Permanently** - Добавляет ресурс пак в список для всех файлов

        * **Type** - Изменяет тип ресурс пака (Необходимо для оптимизации процесса поиска текстуры)

            **Automatic (по умолчанию)** - Определяет тип ресурс пака автоматически

            **Texture & PBR** - Пак с обычными и PBR текстурами

            **Texture** - Пак с обычными текстурами

            **PBR** - Пак с PBR текстурами
        
        ## Apply Resource packs
        Описание: Функция для применения ресурс паков

        ### Настройки:
        * **Combine Duplicates** - Объединяет дублирующиеся текстуры в разных материалах
        * **Use Image Texture** - Заменяет обычные текстуры на текстуры из ресурс пака
        * **Use PBR Textures** - Заменяет PBR текстуры на PBR текстуры
        * **Animate Textures** - Анимирует текстуры

            **Interpolate** - Включает интерполяцию анимации текстур
            
            **Randomize Speed** - Рандомизирует скорость для каждого фейса модели

    </TabItem>

    <TabItem label="Environment" value="environment">
        Описание: Раздел для работы с откружением

        ## Create Environment
        Описание: Набор функций, которые создают откружение прямо как в майнкрафте с шейдерами

        ### Что делает эта фича ?
        Создаёт небо, облака и туман

        ### Настройки:

        * **Create Clouds** - Создаёт облака
        * **Create Sky** - Создаёт небо
        * **Create Fog** - Создаёт туман

        ## Recreate Environment
        Описание: Функция для восстановления неба, облаков и тумана, если они сломаны.

        ### Что делает эта фича ?
        Фича имеет несколько режимов работы:

        * **Reset Settings** - Сбрасывает настройки неба
        * **Create Sky** - Добавляет небо из файла, например вы не удалили,а просто заменили небо на другое, тогда эта функция поможет вернуть его на место
        * **Create Clouds** - Добавляет облака из файла, например вы не удалили,а просто заменили облака на другое, тогда эта функция поможет вернуть их на место
        * **Create Fog** - Добавляет туман из файла, например вы не удалили,а просто заменили туман на другое, тогда эта функция поможет вернуть его на место
        * **Recreate Sky** - Полностью удаляет, а затем добавляет небо
        * **Recreate Clouds** - Полностью удаляет, а затем добавляет облака
        * **Recreate Fog** - Полностью удаляет, а затем добавляет туман
    </TabItem>

    <TabItem label="PPBR" value="ppbr">
        Описание: Раздел для улучшения внешнего вида материалов

        ## Set Procedural PBR
        Описание: Функция для улучшения внешнего вида материалов

        ### Что делает эта фича ?
        Улучшает внешний вид материалов

        ### Настройки:
        1. **Use Normals** - Создаёт процедурные нормалей, либо ноду bump
        2. **Better Emission** - Улучшает излучение материалов
        3. **Procedural Animation** - Создаёт процедурную анимацию излучения от блоков
        4. **Change PBSDF Settings** - Изменяет параметр Specular и Roughness для каждого материала
        5. **Add SSS** - Добавляет SSS для таких материалов как трава и листва
        6. **Add Translucency** - Добавляет полупрозрачность для листвы
        7. **Add Metallic** - Добавляет металичность для металлов и подобных материалов
        8. **Add Roughness** - Изменяет roughness для всяких отражающих блоков по типу стекла, металлов и т.п
    </TabItem>
