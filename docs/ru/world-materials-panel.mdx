# World

## Fix World
Описание: Функция для оптимизации и исправления материалов мира Minecraft

### Что делает эта фича ?

1. Устанавливает режим прозрачности на Dithered (Hashed) для корректного отображения прозрачных текстур
2. Настраивает правильную интерполяцию текстур для сохранения пиксельной графики
3. Корректно соединяет альфа-канал текстуры с прозрачностью материала (Principled BSDF)
4. Автоматически настраивает эмиссию для светящихся блоков, подключая текстуру к параметру Emission

### Настройки:

* Backface Culling - Включает отсечение задних граней для прозрачных блоков (стекло, листва и т.д.)

* Delete Useless Textures - Очищает материалы от неиспользуемых текстурных нод для оптимизации

* Lazy Biome Color Fix - Добавляет цветокоррекцию для травы в соответствии с цветом биома

# Environment

## Create Environment
Описание: Набор функций, которые создают откружение прямо как в майнкрафте с шейдерами

### Что делает эта фича ?
Создаёт небо, облака и туман

### Настройки:

* Create Clouds - Создаёт облака
* Create Sky - Создаёт небо
* Create Fog - Создаёт туман

## Recreate Environment
Описание: Функция для восстановления неба, облаков и тумана, если они сломаны.

### Что делает эта фича ?
Фича имеет несколько режимов работы:

* Reset Settings - Сбрасывает настройки неба
* Create Sky - Добавляет небо из файла, например вы не удалили,а просто заменили небо на другое, тогда эта функция поможет вернуть его на место
* Create Clouds - Добавляет облака из файла, например вы не удалили,а просто заменили облака на другое, тогда эта функция поможет вернуть их на место
* Create Fog - Добавляет туман из файла, например вы не удалили,а просто заменили туман на другое, тогда эта функция поможет вернуть его на место
* Recreate Sky - Полностью удаляет, а затем добавляет небо
* Recreate Clouds - Полностью удаляет, а затем добавляет облака
* Recreate Fog - Полностью удаляет, а затем добавляет туман

# Procedural PBR (PPBR)
Описание: Раздел для улучшения внешнего вида материалов

## Set Procedural PBR

### Что делает эта фича ?
Улучшает внешний вид материалов

### Настройки:
1. Изменяет параметр Specular и Roughness для каждого материала
2. Создаёт процедурных нормалей, либо создание ноды bump
3. Улучшает излучение материалов
4. Создаёт Процедурная анимация излучения от блоков
5. Добавляет SSS для таких материалов как трава и листва
6. Добавляет полупрозрачность для листвы
7. Добавляет металичность для металлов и подобных материалов
8. Изменяет roughness для всяких отражающих блоков по типу стекла, металлов и т.п
