# 🦋 V0.7.0 Butterfly 🦋

## Что нового ?

- **Absolute Solver v2** [Issue #55](https://github.com/Aspirata/MiBlend/issues/55):  
  Absolute Solver теперь предоставляет более понятные и информативные сообщения об ошибках. Также, Absolute Solver теперь может предоставить автоматическое решение для некоторых проблем.

- **Автоматическое обновление встроенных паков** [Issue #78](https://github.com/Aspirata/MiBlend/issues/78):  
  Теперь встроенные текстурные паки будут обновляться автоматически без необходимости делать это вручную.

- **Постоянные ресурс-паки** [Issue #51](https://github.com/Aspirata/MiBlend/issues/51):  
  Вы можете добавить любимые текстурные паки, которые всегда будут в аддоне, не требуя повторного добавления.

- **Объединение дубликатов** [Issue #46](https://github.com/Aspirata/MiBlend/issues/46):  
  В ресурс-паках появилась новая функция, которая автоматически объединяет дублирующиеся текстуры в разных материалах.
  Например, `grass.png` и `grass.png.001` теперь будут объединены в одну текстуру `grass.png`, что обеспечивает корректную работу с ресурс-паками.

- **Замена текстур в группах нод через ресурс-паки** [Issue #82](https://github.com/Aspirata/MiBlend/issues/82):  
  Теперь вы можете легко заменять текстуры в группах нод с помощью ресурс-паков. Это особенно полезно для работы с ригами и другими ассетами.

- **Поддержка Minecraft 1.21.6** [Issue #84](https://github.com/Aspirata/MiBlend/issues/84):  
  Аддон теперь полностью совместим с последней версией Minecraft 1.21.6.

- **Русский перевод для Absolute Solver** [Issue #36](https://github.com/Aspirata/MiBlend/issues/36):  
  Добавлен русский перевод для Absolute Solver. Теперь ошибки и их описания будут доступны на русском языке.

- **Аниматор текстур в ассетах** [Issue #91](https://github.com/Aspirata/MiBlend/issues/91):  
  Теперь вы можете добавить аниматор текстур отдельно в свои материалы через ассеты.

- **Поддержка bump из blender 4.4** [Commit 2b64cd4](https://github.com/Aspirata/MiBlend/commit/2b64cd43fce47179e6f24bc30915d53da8403c21):  
  Теперь аддон поддерживает bump из Blender 4.4.
