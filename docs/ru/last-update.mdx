# 🦋 V0.7.0 Butterfly 🦋

## Что нового?

- **Absolute Solver v2** [Issue #55](https://github.com/Aspirata/MiBlend/issues/55)  
  Теперь предоставляет более понятные и информативные сообщения об ошибках и автоподсказки для решения некоторых из них.

- **Авто‑обновление встроенных паков** [Issue #78](https://github.com/Aspirata/MiBlend/issues/78)  
  Встроенные текстурные паки обновляются автоматически без вашего участия.

- **Постоянные ресурс‑паки** [Issue #51](https://github.com/Aspirata/MiBlend/issues/51)  
  Добавляйте любимые текстурные паки навсегда — они останутся в аддоне между сессиями.

- **Объединение дубликатов** [Issue #46](https://github.com/Aspirata/MiBlend/issues/46)  
  Дублирующиеся текстуры (например, `grass.png` и `grass.png.001`) теперь автоматически сливаются в одну.

- **Замена текстур в группах нод** [Issue #82](https://github.com/Aspirata/MiBlend/issues/82)  
  Лёгкая замена текстур внутри нод‑групп через ресурс‑паки, удобно для ригов и кастомных ассетов.

- **Поддержка Minecraft 1.21.6** [Issue #84](https://github.com/Aspirata/MiBlend/issues/84)  
  Полная совместимость с последней версией игры.

- **Русский перевод Absolute Solver** [Issue #36](https://github.com/Aspirata/MiBlend/issues/36)  
  Ошибки и подсказки теперь доступны на русском языке.

- **Аниматор текстур в ассетах** [Issue #91](https://github.com/Aspirata/MiBlend/issues/91)  
  Добавлена возможность отдельно анимировать текстуры через систему ассетов.

- **Поддержка bump из Blender 4.4** [Commit 2b64cd4](https://github.com/Aspirata/MiBlend/commit/2b64cd43fce47179e6f24bc30915d53da8403c21)  
  Теперь MiBlend корректно работает с новой реализацией bump‑карты.

## Исправления

- **Первый запуск и включение/выключение аддона**  
  Аддон больше не «падает» при первой активации и стабильно реагирует на переключение.

- **Текстуры нормалей**  
  Нормали теперь отображаются корректно — высота не инвертируется. Спасибо XBXR!

- **Скорость анимации текстур** [Issue #50](https://github.com/Aspirata/MiBlend/issues/50)  
  Анимация текстур привязана к игровому времени. Спасибо BlueEvil!

- **Замена текстур табличек** [Issue #94](https://github.com/Aspirata/MiBlend/issues/94)  
  Текстуры табличек заменяются корректно через Apply Resource Pack.

---

## Изменения

- **Перезапуск не требуется**  
  Deprecated и Experimental функции больше не требуют перезапуска аддона.

- **Better Emission v2** [Issue #81](https://github.com/Aspirata/MiBlend/issues/81)  
  Улучшена точность свечения, устранено предупреждение о сложных драйверах.

- **Ресурс‑пак Bare Bones обновлён до v1.4.6** [Issue #81](https://github.com/Aspirata/MiBlend/issues/81)  
  Новая версия адаптирована под Minecraft 1.21.6.
