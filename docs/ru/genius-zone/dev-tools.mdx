# Инструменты

## dprint
Описание: Функция для вывода информации в консоль

Самая полезная функция, которая выводит информацию в консоль.

P.S Её отличие от print в том, что она работает только при включённых Dev Tools, что позволяет не засорять консоль вне процесса разработки.

### Как использовать ?
Сама функция:
```python
dprint(*messages: str, is_deep: bool =False, zone: str =None, separate: bool =False)
```

Пример:
```python
dprint(f"Material: {material.name}", is_deep=True, zone="fw")
```

* ```f"Material: {material.name}"``` - Выводит в консоль сообщения, может принимать бесконечное количество аргументов
* ```is_deep=True``` - Выводит в консоль сообщения только при включённом Deep Debug
* ```zone="fw"``` - Выводит в консоль сообщения только при включённом Fix World Debug Mode

### Поднастройки

* **Deep Debug** - Режим глубокой отладки, например для отладки функций по нахождению текстур в ресурс-паках
* **Fix World Debug Mode** - Режим отладки для Fix World
* **Fix World Debug Mode** - Режим отладки для Fix Materials

Описание: Функции для отладки

Добавляет в UI кнопки для отладки. Например, чтобы удалить список ассетов или список ресурс-паков
