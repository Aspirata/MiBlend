## What is MiBlend ?

MiBlend is an addon for Blender that simplifies the creation of Minecraft content.

## What's the difference between MiBlend and Mcprep ?

These are completely different addons created by different developers. Some ideas from MCprep were adapted and reworked in MiBlend, but their implementation is significantly different.

## Which is better: MCprep or MiBlend ?

It's hard to determine a clear leader since both addons have different priorities. MiBlend focuses on modern technologies, the latest versions of Blender and Minecraft, and provides advanced settings.
MCprep emphasizes backward compatibility (support for older Blender versions) and ease of use.

## Why do we need MiBlend ?

MCprep has several significant limitations:
- Most rigs work incorrectly in new versions of Blender
- Problems with animated textures
- Unable to animate textures on spawned blocks
- Extra materials on placed blocks
- Complex and confusing node structure in prepped materials
- Other issues described on [GitHub](https://github.com/Moo-Ack-Productions/MCprep/issues)

These problems have remained unsolved for a long time, which led to the creation of MiBlend. My addon not only solves all the above problems but also provides more features with better implementation.
Although MiBlend is in beta version and may contain some bugs, by the release of version 1.0, all functions will be fully implemented and debugged.

## Can I use MiBlend together with Mcprep ?

Technically it's possible, but not recommended. MiBlend uses its own methods of improving materials that may conflict with MCprep or work unpredictably.

## Wait, MiBlend? What happened to Mcblend ?

The addon was renamed from Mcblend to MiBlend to avoid confusion with the existing Mcblend addon by developer nosiq.
