# 🦋 V0.7.0 Butterfly 🦋

## What’s New?

- **Absolute Solver v2** [Issue #55](https://github.com/Aspirata/MiBlend/issues/55)  
  Provides clearer, more informative error messages and auto‑fix suggestions for certain issues.

- **Auto‑Update Built‑In Packs** [Issue #78](https://github.com/Aspirata/MiBlend/issues/78)  
  Built‑in texture packs now update automatically without manual intervention.

- **Persistent Resource Packs** [Issue #51](https://github.com/Aspirata/MiBlend/issues/51)  
  Add your favorite texture packs permanently—they’ll stay in the add‑on across sessions.

- **Duplicate Merging** [Issue #46](https://github.com/Aspirata/MiBlend/issues/46)  
  Automatically merges duplicate textures (e.g., `grass.png` and `grass.png.001`) into one.

- **Node‑Group Texture Replacement** [Issue #82](https://github.com/Aspirata/MiBlend/issues/82)  
  Easily swap textures inside node groups via resource packs—ideal for rigs and custom assets.

- **Minecraft 1.21.6 Support** [Issue #84](https://github.com/Aspirata/MiBlend/issues/84)  
  Full compatibility with the latest game version.

- **Russian Translation for Absolute Solver** [Issue #36](https://github.com/Aspirata/MiBlend/issues/36)  
  Error messages and descriptions are now available in Russian.

- **Texture Animator in Assets** [Issue #91](https://github.com/Aspirata/MiBlend/issues/91)  
  Add a standalone texture animator to your materials through the asset system.

- **Blender 4.4 Bump Support** [Commit 2b64cd4](https://github.com/Aspirata/MiBlend/commit/2b64cd43fce47179e6f24bc30915d53da8403c21)  
  MiBlend now fully supports the updated bump implementation from Blender 4.4.

---

## Fixes

- **First‑Run & Enable/Disable Issues**  
  The add‑on no longer crashes on first activation and handles toggling reliably.

- **Normal Map Textures**  
  Normals now display correctly—height maps are no longer inverted. Thanks to XBXR!

- **Texture Animation Speed** [Issue #50](https://github.com/Aspirata/MiBlend/issues/50)  
  Animations now sync with in‑game time. Thanks to BlueEvil!

- **Sign Texture Replacement** [Issue #94](https://github.com/Aspirata/MiBlend/issues/94)  
  Sign textures are now replaced correctly via Apply Resource Pack.

---

## Changes

- **No More Restarts**  
  Deprecated and experimental features no longer require an add‑on restart.

- **Better Emission v2** [Issue #81](https://github.com/Aspirata/MiBlend/issues/81)  
  Enhanced glow accuracy and fixed complex‑driver warnings.

- **Bare Bones Pack Updated to v1.4.6** [Issue #81](https://github.com/Aspirata/MiBlend/issues/81)  
  Updated for Minecraft 1.21.6.

---

## Genius Zone

- **Settings Override** [Issue #9](https://github.com/Aspirata/MiBlend/issues/9)  
  User settings now persist across add‑on toggles.

- **Deep Debugging with dprint** [Issue #68](https://github.com/Aspirata/MiBlend/issues/68)  
  Advanced debug modes with zona‑based separation (Resource Packs, Fix World, etc.).
