---
title: Branch Installation Guide  
description: Steps to install any MiBlend branch  
---

<Steps>
  <Step title="Download a Branch" icon="download">
    Go to <a href="https://github.com/Aspirata/MiBlend">GitHub</a> and download the branch you need.
  </Step>

  <Step title="Install Python" icon="python">
    Download and install Python from the <a href="https://www.python.org/downloads/">official website</a>.
  </Step>

  <Step title="Run build_windows.bat" icon="file-code">
    In the root folder of the downloaded branch, locate and execute:  
    ```bash
    build_windows.bat
    ```
    This script will automatically fetch and install all dependencies.
  </Step>

  <Step title="Done" icon="check">
    MiBlend is now installed and ready to use on any Blender version 3.6 or newer!
  </Step>
</Steps>
