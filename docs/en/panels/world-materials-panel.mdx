# Sections

<Tabs>
  <TabItem label="World" value="world">

  **“World” Section** — correction and optimization of game worlds.

  ## Fix World
  **Functionality:** automatic adjustment of materials and textures for correct display in Minecraft.

  **What it does:**
  1. Sets the transparency mode to Dithered (Hashed) for proper rendering of semi-transparent textures.  
  2. Configures texture filtering to “no filter” to preserve crisp pixel art.  
  3. Integrates the texture’s alpha channel with the material’s transparency (Principled BSDF).  
  4. Connects the emission map for glowing blocks to the Emission parameter.

  **Settings:**
  - **Backface Culling** — enables removal of hidden faces for glass, leaves, and other transparent elements.  
  - **Delete Useless Textures** — removes unused texture nodes from materials.  
  - **Lazy Biome Color Fix** — applies a basic grass color correction based on the biome’s color.

  </TabItem>

  <TabItem label="Resource Packs" value="resource-packs">

  **“Resource Packs” Section** — managing the list of resource packs and applying them.

  ## Reload Default Packs
  **Functionality:** refreshes MiBlend’s built-in resource packs.

  **What it does:**
  1. Clears the list of default built‑in packs.  
  2. Checks for newer versions of the built‑in packs.  
  3. Adds all packs from the Resource Packs folder to the list.

  ## Add Resource Pack
  **Functionality:** adds custom resource packs.

  **What it does:**
  - Includes the selected folder or archive in the overall list.

  **Parameters:**
  - **Mode (Temporarily / Permanently)**
    - **Temporarily (default)** — applies only to the current project.  
    - **Permanently** — makes the pack available in all projects.  
  - **Type**
    - **Automatic (default)** — automatically detects the pack type.  
    - **Texture & PBR** — contains both classic and PBR textures.  
    - **Texture** — classic textures only.  
    - **PBR** — PBR textures only.

  ## Apply Resource Packs
  **Functionality:** bulk application of resource packs to materials.

  **Settings:**
  - **Combine Duplicates** — merges duplicate textures.  
  - **Use Image Texture** — replaces default textures with images from the pack.  
  - **Use PBR Textures** — applies PBR maps.  
  - **Animate Textures**
    - **Interpolate** — smooths the animation.  
    - **Randomize Speed** — assigns a random speed to each frame.

  </TabItem>

  <TabItem label="Environment" value="environment">

  **“Environment” Section** — creation and restoration of Minecraft‑style environment elements.

  ## Create Environment
  **Functionality:** generates sky, clouds, and fog using shaders.

  **Settings:**
  - **Create Clouds** — generates clouds.  
  - **Create Sky** — adds the sky.  
  - **Create Fog** — enables fog.

  ## Recreate Environment
  **Functionality:** restores environment elements if they are damaged or replaced.

  **Modes:**
  - **Reset Settings** — resets all environment parameters.  
  - **Create Sky / Add Sky** — restores the sky from the original file.  
  - **Create Clouds / Add Clouds** — brings back clouds.  
  - **Create Fog / Add Fog** — restores fog.  
  - **Recreate Sky / Clouds / Fog** — fully removes and then re‑adds the selected element.

  </TabItem>

  <TabItem label="Materials" value="materials">

  **“Materials” Section** — simplified and accelerated tools for working with materials.

  ## Fix Materials
  **Functionality:** basic material setup for correct rendering.

  **What it does:**
  1. Sets Dithered transparency.  
  2. Configures crisp texture filtering.  
  3. Links the texture’s alpha channel to the Principled BSDF transparency.

  ## Swap Textures
  **Functionality:** replaces textures within materials.

  **What it does:**
  - Searches for texture files with matching names in the specified folder and swaps them into the material.

  </TabItem>

  <TabItem label="PPBR" value="ppbr">

  **“PPBR” Section** — advanced PBR effects for materials.

  ## Set Procedural PBR
  **Functionality:** enhances material appearance with procedural effects.

  **Settings:**
  1. **Use Normals** — generates normals or a bump node.  
  2. **Procedural Emission & Animation** — creates procedural glow and animation.  
  3. **Change BSDF Settings** — adjusts Specular and Roughness.  
  4. **Use SSS** — adds sub‐surface scattering (SSS) effects for grass and leaves.  
  5. **Use Translucency** — introduces translucency for foliage.  
  6. **Make Metal** — increases metallic properties for metal‐like materials.  
  7. **Make Reflections** — lowers Roughness to enhance reflections.

  </TabItem>
</Tabs>
