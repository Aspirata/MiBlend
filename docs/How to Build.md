# Windows:
1. Download any branch
2. Make sure you have python installed on your computer, if not, install it [from here](https://www.python.org/downloads/).
3. Run build_windows.bat
4. That's all, folks

# Linux
1. Download any branch
2. Make sure you have python installed on your comp, if not, install via your distro's batchman (Usually python is not installed on arch, so here's the command for it sudo pacman -S python)
3. Install bab via the pip install bpy-addon-build command
4. Write the bab command in the MiBlend folder (Not in the MiBlend_Source folder !).
5. That's all, folks
